そもそも本研究では良いコードというものの定量的なゴールを定義する必要がある。
それを踏まえ、良いコードの定義を分析哲学、オンとロージー工学の観点から提唱してある、先行研究における検索結果を以下に示す

前回の解説で触れたアプローチや概念を裏付ける、代表的な先行研究および重要論文の引用元（DOIやリンク情報）をまとめました。

### 1. 意味論・言語的アプローチと統計的優位性（概念的凝集度: C3）

コード内の識別子やコメント（言語情報）の意味論的距離をベクトル化し、従来の構造的メトリクスよりも欠陥（バグ）予測において統計的に優位であることを証明した金字塔的な論文です。

- **論文名:** Using the Conceptual Cohesion of Classes for Fault Prediction in Object-Oriented Systems
    
- **著者:** A. Marcus, D. Poshyvanyk, R. Ferenc
    
- **掲載誌:** IEEE Transactions on Software Engineering, Vol. 34, No. 4, 2008.
    
- **DOI:** [10.1109/TSE.2008.34](https://www.google.com/search?q=https://doi.org/10.1109/TSE.2008.34)
    
- **概要:** 潜在意味解析（LSI）を用いてコードの「概念的凝集度（C3）」を定量化し、この指標が従来のメトリクス（LCOMなど）よりも将来のソフトウェア欠陥を正確に予測できることを統計的・経験的に実証しています。
    

### 2. オントロジー工学とコード構造の写像（BWWオントロジー）

現実世界のオントロジー（存在論）をオブジェクト指向の設計やコードのクラス構造にどのようにマッピングすべきか、そしてその「ズレ」をどう捉えるかを論じた代表的な研究です。

- **論文名:** Toward an ontology for object-oriented analysis and design
    
- **著者:** Joerg Evermann, Yair Wand
    
- **掲載誌:** ACM Transactions on Database Systems (TODS), Vol. 30, Issue 2, 2005.
    
- **DOI:** [10.1145/1071610.1071613](https://www.google.com/search?q=https://doi.org/10.1145/1071610.1071613)
    
- **概要:** Bungeのオントロジー（BWWモデル）をオブジェクト指向設計に適用し、現実世界とプログラム構造の間のオントロジー的な欠落や過負荷（1つのクラスが複数の現実概念を担ってしまう状態など）を評価するルールを提示しています。
    

### 3. 分析哲学的基盤（理論構築としてのプログラミング）

コードの「言語・意味」を重視する現代のソフトウェア工学哲学の原点とも言える、チューリング賞受賞者ピーター・ナウアの古典的論文です。

- **論文名:** Programming as Theory Building
    
- **著者:** Peter Naur
    
- **掲載誌:** Microprocessing and Microprogramming, Vol. 15, Issue 5, 1985.
    
- **DOI:** [10.1016/0165-6074(85)90032-8](https://www.google.com/search?q=https://doi.org/10.1016/0165-6074\(85\)90032-8)
    
- **概要:** プログラミングの本質は、テキストとしてのコードを記述することではなく、対象領域（現実世界）に対する「理論（理解の体系）」を開発者の頭脳の中で構築することであると論じています。コードの明証性や命名規則の哲学的な根拠として頻繁に引用されます。
    

### 4. 認知負荷と理解のしやすさの定量化（認知的複雑度）

現代の静的解析ツール（SonarQubeなど）で広く採用されている「認知的複雑度」の原論文です。人間の「読みやすさ」を数学的・構造的に定量化し、バグの温床を予測します。

- **論文名:** Cognitive Complexity - A new way of measuring understandability
    
- **著者:** G. Ann Campbell
    
- **発表:** SonarSource White Paper / IEEE International Conference on Software Analysis, Evolution and Reengineering (SANER), 2018.
    
- **DOI:** [10.1109/SANER.2018.8330268](https://www.google.com/search?q=https://doi.org/10.1109/SANER.2018.8330268)
    
- **概要:** 従来の循環的複雑度（Cyclomatic Complexity）の限界を指摘し、人間の認知プロセス（直感に反するネスト、論理の飛びなど）にペナルティを与える新しい計算モデルを提唱しています。
